## 🔍 测试步骤

### 步骤1：登录账号
1. 打开小程序
2. 使用测试账号登录（如 `student3` / `123456`）

### 步骤2：进入身份认证页面
1. 点击"我的"页面
2. 点击"个人信息"或"身份认证"
3. 进入 `personal-info` 页面

### 步骤3：填写认证信息
1. **真实姓名**：输入任意姓名（如：张三）
2. **学号/工号**：输入白名单中的学号或工号（如：`2021001001`）
3. **身份证号**：输入符合格式的身份证号（如：`110101199001011234`）

### 步骤4：提交认证
1. 点击"提交认证"按钮
2. 等待接口返回结果

### 步骤5：验证结果
1. 如果认证成功：
   - 显示"身份认证成功"提示
   - 页面自动返回上一页
   - 在"我的"页面可以看到"✓ 已认证"状态
   - 显示具体角色（学生/教师/外部人员）

2. 如果认证失败：
   - 显示错误提示信息
   - 检查学号/工号是否在白名单中
   - 检查身份证号格式是否正确

## 📌 注意事项

1. **身份证号格式**：
   - 必须是18位
   - 符合中国身份证号规则
   - 前6位为地区码，中间8位为出生日期，最后4位为顺序码和校验码

2. **学号/工号匹配**：
   - 系统会精确匹配白名单中的 `identityNumber`
   - 大小写敏感
   - 必须完全一致

3. **角色自动识别**：
   - 如果学号/工号在白名单中，系统会根据白名单的 `roleType` 设置角色
   - 如果不在白名单中，系统会设置为 `outsider`

4. **认证状态**：
   - 认证成功后，`idStatus` 会更新为 `verified`
   - 已认证的用户无法再次提交认证（除非后端允许）

5. **Token 有效期**：
   - 确保 Token 未过期
   - 如果 Token 过期，需要重新登录

## 🐛 常见问题排查

### 问题1：认证失败，提示"白名单不存在或信息不匹配"
**原因：**
- 学号/工号不在白名单中
- 白名单状态为 `inactive`

**解决：**
- 使用文档中提供的白名单学号/工号
- 或联系管理员添加白名单

### 问题2：提示"未登录"
**原因：**
- Token 已过期
- 未携带 Token

**解决：**
- 重新登录获取新 Token
- 检查请求头是否包含 `Authorization: Bearer <token>`

### 问题3：前端提示"请填写所有必填项"
**原因：**
- 表单验证失败
- 有必填项为空

**解决：**
- 检查所有必填项是否已填写
- 检查输入框是否有值

### 问题4：身份证号验证失败
**原因：**
- 身份证号格式不正确
- 长度不是18位

**解决：**
- 使用符合格式的身份证号
- 参考文档中的示例身份证号

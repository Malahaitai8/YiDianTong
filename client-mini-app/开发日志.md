### 🔌 API接口设计

#### 科室相关（4个接口）
```
GET /departments              # 获取所有科室
GET /departments/{id}         # 获取科室详情
GET /departments/search       # 搜索科室
GET /departments/{id}/doctors # 获取科室医生
```

#### 医生相关（4个接口）
```
GET /doctors                  # 获取医生列表
GET /doctors/{id}             # 获取医生详情
GET /doctors/search           # 搜索医生
GET /doctors/{id}/schedules   # 获取医生排班
```

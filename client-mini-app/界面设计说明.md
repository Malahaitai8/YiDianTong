# 医点通小程序 - 界面设计说明文档

## 🎨 设计概览

本次重新设计了医点通小程序的患者端界面，采用**健康蓝色系**的UI风格，设计简洁直观、易于上手，所有宽度尺寸以 **750rpx** 为基准。

---

## 📱 页面结构

### 1. 底部导航栏（Tab Bar）

共4个Tab，采用文本模式（可后期添加图标）：

| Tab | 页面路径 | 功能说明 |
|-----|---------|---------|
| 首页 | `/pages/index/index` | 挂号导航、就诊提醒、智能问答入口 |
| 挂号 | `/pages/appointment/appointment` | 线上挂号预约（占位页面） |
| 记录 | `/pages/records/records` | 就诊记录查询（占位页面） |
| 我的 | `/pages/profile/profile` | 个人中心、账户管理 |

**设计特点**：
- 选中色：`#1976d2`（主题蓝）
- 未选中色：`#666666`（灰色）
- 背景色：`#ffffff`（白色）

## 🎯 交互逻辑

### 登录状态管理
- 使用 **Vuex** 存储用户 token 和信息
- `localStorage` 持久化 token
- 路由拦截器控制页面访问权限

### 白名单路由
以下页面无需登录即可访问：
- `/pages/index/index` - 首页
- `/pages/login/login` - 登录页
- `/pages/register/register` - 注册页
- `/pages/appointment/appointment` - 挂号页（TabBar）
- `/pages/records/records` - 记录页（TabBar）
- `/pages/profile/profile` - 我的页（TabBar）

### 权限控制
- **TabBar页面**：允许访问，但部分功能需要登录
- **其他页面**：未登录自动跳转到登录页
- **核心功能**：点击时检查登录状态

## 🎨 设计规范

### 颜色规范

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色 | `#1976d2` | 按钮、强调色 |
| 辅助色 | `#42a5f5` | 渐变、图标背景 |
| 成功色 | `#4caf50` | 已认证徽章 |
| 警告色 | `#ff9800` | 未认证徽章、提示 |
| 错误色 | `#f44336` | 退出按钮、错误提示 |
| 文字主色 | `#333` | 标题、正文 |
| 文字辅色 | `#666` | 次要信息 |
| 文字提示色 | `#999` | 占位符、提示 |
| 背景色 | `#f5f7fa` | 页面背景 |

### 圆角规范
- **大卡片**：20rpx - 25rpx
- **小卡片**：15rpx
- **输入框**：12rpx
- **按钮**：15rpx
- **圆形**：50%

### 阴影规范
- **卡片阴影**：`0 4rpx 15rpx rgba(0, 0, 0, 0.05)`
- **按钮阴影**：`0 8rpx 20rpx rgba(25, 118, 210, 0.3)`
- **搜索框阴影**：`0 4rpx 20rpx rgba(25, 118, 210, 0.15)`

### 字体规范
- **大标题**：48rpx（Logo）
- **标题**：36rpx（页面标题）
- **副标题**：32rpx（按钮、用户名）
- **正文**：28rpx（表单标签、列表项）
- **辅助文字**：24rpx（提示、标签）
- **说明文字**：22rpx（注释、字数统计）

### 间距规范
- **页面边距**：30rpx
- **卡片间距**：30rpx
- **表单项间距**：25rpx - 35rpx
- **小元素间距**：10rpx - 15rpx

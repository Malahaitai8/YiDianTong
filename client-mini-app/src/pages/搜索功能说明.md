# 科室/医生搜索功能开发说明

## 📝 功能概述

本次开发完成了小程序端的**科室/医生搜索**功能，包括搜索、列表展示、详情查看和挂号预约流程。

## ✅ 已完成功能

### 1. 搜索页面 (`pages/search/search.vue`)

**核心功能：**
- 🔍 **智能搜索**：支持科室和医生两种搜索模式切换
- 📝 **实时搜索**：输入关键词后自动触发搜索（500ms防抖）
- 📚 **搜索历史**：自动保存最近10条搜索记录
- 🔥 **热门推荐**：展示热门科室和医生
- 🎯 **精准匹配**：高亮显示搜索结果

**交互特点：**
- Tab切换（科室/医生）
- 点击历史记录快速搜索
- 清空搜索历史功能
- 空状态友好提示

## 🔌 API接口设计

### 科室相关接口 (`api/department.js`)

```javascript
// 获取所有科室列表
GET /departments

// 根据ID获取科室详情
GET /departments/{id}

// 搜索科室
GET /departments/search?keyword={keyword}

// 获取科室的医生列表
GET /departments/{departmentId}/doctors
```

### 医生相关接口 (`api/doctor.js`)

```javascript
// 获取所有医生列表（可按科室、职称筛选）
GET /doctors?departmentId={id}&title={title}

// 根据ID获取医生详情
GET /doctors/{id}

// 搜索医生
GET /doctors/search?keyword={keyword}

// 获取医生排班信息
GET /doctors/{doctorId}/schedules?startDate={date}&endDate={date}
```

## 🚀 使用说明

### 1. 启动项目
```bash
cd client-mini-app
npm install
npm run dev:h5
```

### 2. 测试流程
1. 打开首页
2. 点击搜索框进入搜索页面
3. 输入"呼吸"搜索科室
4. 点击科室查看该科室的医生
5. 点击医生查看详情
6. 选择日期和时间段
7. 点击"立即挂号"（需要登录）

### 3. 数据准备
需要后端提供以下数据：
- 至少4个科室（内科、外科、儿科、妇产科）
- 每个科室至少5位医生
- 医生的排班信息（未来7天）

# TabBar 图标说明

此目录用于存放底部导航栏的图标文件。

## 需要的图标文件

### 首页
- `home.png` - 未选中状态（灰色）
- `home-active.png` - 选中状态（蓝色）

### 挂号
- `appointment.png` - 未选中状态（灰色）
- `appointment-active.png` - 选中状态（蓝色）

### 记录
- `records.png` - 未选中状态（灰色）
- `records-active.png` - 选中状态（蓝色）

### 我的
- `profile.png` - 未选中状态（灰色）
- `profile-active.png` - 选中状态（蓝色）

## 图标规格要求

- 尺寸：建议 81px × 81px
- 格式：PNG（支持透明背景）
- 颜色：
  - 未选中：#666666（灰色）
  - 选中：#1976d2（蓝色）

## 图标设计建议

1. **首页**：房子/主页图标
2. **挂号**：日历/预约图标
3. **记录**：文档/列表图标
4. **我的**：用户/个人图标

## 临时方案

如果暂时没有图标，可以使用文本模式的TabBar（已在代码中提供备选方案）。

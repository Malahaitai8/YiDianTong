# 项目结构说明

本文档详细说明易点通挂号系统后端项目的代码结构。

## 包结构说明

### 1. `com.example.springboot.common` - 通用类
- **Result.java**: 统一响应结果封装类
  - 所有 API 接口统一返回 `Result` 类型
  - 包含 `code`（状态码）、`msg`（消息）、`data`（数据）三个字段

### 2. `com.example.springboot.config` - 配置类

#### 安全配置
- **SecurityConfig.java**: Spring Security 核心配置
  - CORS 跨域配置
  - JWT 过滤器配置
  - 接口权限控制
  - 密码编码器配置
  
- **JwtUtil.java**: JWT 工具类
  - Token 生成
  - Token 验证
  - Token 解析

- **JwtAuthenticationFilter.java**: JWT 认证过滤器
  - 拦截请求并验证 JWT Token
  - 将用户信息注入 SecurityContext

- **CustomUserDetailsService.java**: 自定义用户详情服务
  - 实现 Spring Security 的 UserDetailsService
  - 根据用户名加载用户信息

- **CustomUserDetails.java**: 自定义用户详情
  - 实现 Spring Security 的 UserDetails
  - 封装用户信息和权限

- **SecurityUtils.java**: 安全工具类
  - 获取当前登录用户信息
  - 权限判断工具方法

- **PasswordEncoderUtil.java**: 密码编码工具类
  - 密码加密
  - 密码验证

#### 其他配置
- **RedisConfig.java**: Redis 配置类
- **SwaggerConfig.java**: Swagger API 文档配置
- **OpenApiConfig.java**: OpenAPI 配置
- **SystemConfigInitializer.java**: 系统配置初始化器

### 3. `com.example.springboot.constants` - 常量类
- **RoleConstants.java**: 角色常量定义
  - 数据库角色名（小写）：`admin`、`doctor`、`patient`
  - Spring Security 角色名（大写+前缀）：`ROLE_ADMIN`、`ROLE_DOCTOR`、`ROLE_PATIENT`
  - 认证角色名（大写）：`ADMIN`、`DOCTOR`、`PATIENT`
  - 提供角色转换工具方法

### 8. `com.example.springboot.dto` - 数据传输对象（47个）

用于前后端数据传输，包括：
- 请求 DTO（Request）：接收前端请求参数
  - LoginRequest, RegisterRequest, CreateAppointmentRequest 等
  
- 响应 DTO（Response）：返回给前端的数据
  - LoginResponse, AppointmentWithDoctorDTO, DoctorDashboardDTO 等

主要 DTO 类：
- **认证相关**: LoginRequest, LoginResponse, RegisterRequest, ChangePasswordRequest, ResetPasswordRequest
- **预约相关**: CreateAppointmentRequest, RescheduleAppointmentRequest, AppointmentWithDoctorDTO
- **排班相关**: CreateScheduleRequest, UpdateScheduleRequest, ScheduleDTO, ScheduleWithDetailsDTO, ScheduleQueryRequest
- **排班规则相关**: CreateScheduleRuleRequest, UpdateScheduleRuleRequest, ScheduleRuleDetailDTO, ApplyScheduleRuleRequest
- **医生相关**: DoctorCreateRequest, DoctorDashboardDTO, DoctorScheduleDTO, DoctorPatientDTO
- **申请相关**: CreateApplicationRequestDTO, ReviewApplicationRequestDTO, ApplicationRequestDetailDTO
- **其他**: AdminStatisticsDTO, AvailableSlotDTO, WaitlistInfoDTO, QaMatchedFaqDTO 等

### 9. `com.example.springboot.exception` - 异常处理

- **CustomerException.java**: 自定义业务异常
  - 包含 code（错误码）和 msg（错误消息）
  
- **GlobalExceptionHandler.java**: 全局异常处理器
  - 使用 `@ControllerAdvice` 注解
  - 统一处理所有异常并返回标准响应格式
  - 区分业务异常和系统异常

### 10. `com.example.springboot.SpringbootApplication` - 启动类

- 主启动类
- 使用 `@SpringBootApplication` 注解
- 配置 MyBatis 扫描路径：`@MapperScan("com.example.springboot.mapper")`
- 启用事务管理：`@EnableTransactionManagement`

## 项目特点

1. **分层清晰**：严格遵循 Controller → Service → Mapper 三层架构
2. **统一响应**：所有接口统一返回 `Result` 类型
3. **异常处理**：全局异常处理机制，统一异常响应格式
4. **安全认证**：JWT + Spring Security 实现无状态认证
5. **代码简化**：使用 Lombok 简化代码，减少样板代码
6. **API 文档**：集成 Swagger/OpenAPI，自动生成 API 文档
7. **配置管理**：统一的配置管理，便于维护

## 开发规范

1. **命名规范**：
   - Controller 类名以 `Controller` 结尾
   - Service 类名以 `Service` 结尾
   - Mapper 接口名以 `Mapper` 结尾
   - Entity 类名使用大写开头，无后缀
   - DTO 类名以 `DTO`、`Request` 或 `Response` 结尾

2. **代码风格**：
   - 使用 Lombok 的 `@Data` 注解简化实体类
   - 统一使用 `@Autowired` 进行依赖注入
   - 控制器方法统一返回 `Result` 类型

3. **注释规范**：
   - 类和方法添加 JavaDoc 注释
   - 复杂业务逻辑添加行内注释
